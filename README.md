# Seguimiento de práctica clínica

App web estática (sin servidor) para el seguimiento de cadetes en práctica clínica: importa listas de calificaciones y el registro de inasistencias en Excel o CSV, calcula porcentajes de faltas, advertencias, alertas y riesgo académico, y guarda la bitácora de acciones de seguimiento.

La versión publicada va vacía. Los datos que se cargan se guardan solo en el navegador de cada dispositivo (localStorage); no se envían a ningún servidor.

Lectura y exportación de Excel con xlsx-js-style (Apache 2.0), incluido en `vendor/`.
